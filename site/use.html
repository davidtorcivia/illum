Use

Written in Draft

The library is a set of JavaScript modules with no dependencies, not yet published as a package. Copy the kit and fonts folders from this site into yours, side by side, and call rubricate on the element that holds your text.

import { rubricate } from './kit/illum.js';

const r = rubricate(article, { style: 'tarot', draw: 'read' });
r.redraw({ rich: 0.25 });
r.destroy();

Markup

It drawswhere it finds
a drop initial<span class="ini drop"> round the first letter
a paraph<p class="par">
a line-fillerthe free end of a paragraph’s last line
a break<hr>, or <hr data-rank="2"> between books
a frameblockquote, figure, pre, aside, nav

Options

optionvalues
style'blackletter', 'tarot', 'occult', 'astrology', 'draft'
draw'still', or 'read' to write each mark as its line comes into view
rich0 to 1; default 0.5
seeda whole number; default a hash of the text
initialthe style’s drop initial, such as { set: 'solid' }

The page sets --paper, --ink and --rubric, and illum draws in its own inks to suit them, light or dark. The element that holds the text must be positioned. Frames are drawn in the padding of their boxes; this site’s stylesheet has working values for each style. The text is never covered, and with reduced motion nothing is written as the reader watches.
