Once a scribe had finished a book, a rubricator would go over it with red ink and a fine pen. illum brings this craft to the web. The library reviews openings, paragraphs, breaks and quotations in the page’s markup, and then a simulated pen writes a mark for each in beautifully rendered digital ink.

The result is a more beautiful, easier to parse, more alive digital document. illum aims to make the web a touch more delightful.
