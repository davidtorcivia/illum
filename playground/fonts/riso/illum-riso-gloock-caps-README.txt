illum-riso-gloock-caps.woff2 is a subset of Gloock (Duarte Pinto; Copyright 2022 The Gloock Project Authors,
https://github.com/duartp/gloock) (capitals A-Z, accented capitals and figures 0-9 only), made for illum with fontTools
(pyftsubset) and renamed Illum Riso Gloock Caps. Gloock has no Reserved Font Name; the subset is renamed only so that it is
never mistaken for the original. The original font, its copyright and its licence: Gloock-OFL.txt (beside this file).
